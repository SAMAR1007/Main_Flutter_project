## 🚀 Quick Start (5 minutes)

### Backend
```bash
cd backend
npm install
# Create .env with MONGO_URI, JWT_SECRET, PORT
npm run dev
```

### Frontend
```bash
# Update API IP in lib/core/network/api_endpoints.dart
flutter pub get
flutter run
```
